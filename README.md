## 💡 About

**Global Career Network (GCN)** is Arizona State University's largest student-run career organization — helping students land internships and full-time roles through recruiter events, career workshops, and a powerful peer network.

This repository is GCN's **official public website**: the first touchpoint for prospective members, corporate sponsors, and campus partners.

## ✨ What's inside

| Page | Purpose |
|---|---|
| 🏠 **Home** (`index.html`) | Who we are, what we do, and how to join |
| 👥 **E-Board** (`eboard.html`) | Meet the 14-officer leadership team, with headshots |
| 🏆 **Achievements** (`achievements.html`) | Milestones, wins, and impact numbers |

**Design principles:**

| | |
|---|---|
| ⚡ | **Zero-framework, zero-build** — pure HTML/CSS/JS loads instantly on any device |
| 📱 | **Responsive** — looks sharp from phones at the club fair to sponsor boardrooms |
| 🚀 | **Vercel-deployed** — `vercel.json` config, pushes go live in seconds |

## 🚀 Run locally

```bash
git clone https://github.com/GlobalCareerNetwork/GCN_website.git
cd GCN_website
# open index.html in a browser — that's it. No install, no build step.
```

Deploy: import the repo at [vercel.com/new](https://vercel.com/new) — configuration is already committed.

## 🤝 Contributing

Officers and members: open a PR against `main`. Keep it dependency-free — the site's superpower is its simplicity.
